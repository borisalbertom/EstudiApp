# EstudiApp

App web de trivia y gamificación para estudiar en duelos con amigos (ej. PAES) o cursos de
capacitación privados para empresas.

## Cómo correr el proyecto en tu computador (opcional)

No es necesario si solo vas a publicarlo en Netlify — esto es solo si en algún momento quieres
verlo corriendo en tu propio computador.

```
npm install
npm run dev
```

## Variables de entorno

El archivo `.env` (no se sube a GitHub) contiene las claves de conexión a Supabase.
Ver `.env.example` como referencia del formato.
